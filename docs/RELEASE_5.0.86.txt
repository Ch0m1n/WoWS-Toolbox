WoWS Toolbox 5.0.86

- Fix startup failure after automatic game-path detection when one or more supported games are not installed or a previously saved installation path no longer exists.
- Empty optional game paths are now accepted by Set-GamePath. Previously this raised "Cannot bind argument to parameter Path because it is an empty string" before the main window opened.
- Add a regression that exercises normal startup detection (not automated-mode bypass) with no games, only PC installed, removed saved paths, and valid settings.
- Includes 5.0.85's mounted-model path fix: Beatty's Hotchkiss 47mm guns no longer become port tents.

Install over the existing installation. Uninstalling first is not required. Settings and exported models are retained by an in-place update.

Validation: reproduced the reported empty-Path failure before the fix; all startup-path scenarios pass after the fix on PowerShell 7 and Windows PowerShell 5.1. Full desktop self-tests and package checks are required before publication.
