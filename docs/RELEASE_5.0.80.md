# WoWS Toolbox 5.0.80

- Toggle each armor zone independently. Hide a particular zone or display several zones together.
- Add Show all / Hide all controls and clear check marks for enabled zones. Keyboard button activation and pressed state are supported.
- Zone selections work together with the existing armor thickness filter. Loading a new model resets zones to all visible.
- Add a 0–100% waterline opacity slider next to the waterline height control. The default remains 18%; 100% is opaque.
- Includes the permanent camouflage fixes from 5.0.79.

Verification: actual viewer filter functions were tested for individual toggles, multiple selection, all-hidden state, Show all, thickness intersection and accessibility state; existing viewer session regression checks passed. Release GUI/runtime and integrity checks are performed before publication.

Close WoWS Toolbox before installing. Existing settings and exported models are retained.
