WoWS Toolbox 5.0.82

- Speed up lossless base-color and PBR PNG export with compression level 3; resolution, pixels and alpha are unchanged. Existing texture caches remain reusable.
- Reuse the package index and open package files between PBR DD0 lookup and DDS fallback lookup. Unsupported reads fall back to the existing native extractor.
- Avoid repeated PBR cache checks, shared texture hashing and duplicate publishing work. Exported textures remain independent copies of the cache.
- Resolve case differences in PBR package paths, including Preussen's Hull metallic/gloss map.

Performance example: PC Preussen GLB-to-OBJ/texture conversion took 78.2 s before and 18.8 s after with separate empty conversion caches. This is one local measurement of the conversion stage, not total ship extraction time or a guarantee for every ship. With reusable caches, both versions took about 10 s. The same PNG file set grew by about 10%.

Validation: identical OBJ bytes and identical pixels in 308 common PNG pairs; 43 affected Python tests passed. Complete desktop self-tests and installer readiness are checked for this release.
