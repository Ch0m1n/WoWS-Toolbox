# WoWS Toolbox 5.0.59

내 PC에 설치된 World of Warships 계열 게임에서 원하는 함선을 골라 파트별 모델로 내보내고, 프로그램 안에서 모델과 장갑을 바로 확인하는 Windows GUI 도구예요.

지원 소스:

- World of Warships: Legends Steam판
- World of Warships PC판
- Korabli

게임 설치 폴더는 읽기 전용으로 사용해요. 게임 자산과 Oodle DLL은 배포본에 넣지 않아요.

## 5.0.59 모델 뷰어 텍스처·조작 멈춤 수정

- 같은 PNG를 기본 색상(`map_Kd`)과 투명도(`map_d`)로 동시에 읽는 재질에서 비동기 이미지 캐시가 빈 값을 돌려주던 문제를 고쳤어요.
- 잘못된 `ImageBitmap` 때문에 WebGL 렌더 루프가 멈춰 일부 표면이 검거나 불완전하게 보이고, 카메라·파트를 움직여도 화면이 갱신되지 않던 문제를 해결했어요.
- 실제 Mecklenburg G의 508개 파트·93개 재질을 기본/PBR 모드에서 검사해 잘못된 텍스처와 브라우저 오류가 0개인지, 파트 이동·실행 취소 뒤에도 렌더 프레임이 계속 갱신되는지 확인했어요.

## 5.0.58 부분 고유 외형 핫픽스

- `A_Hull`이나 무장 모델을 교체하지 않고 런타임 재질 스타일만 지정하는 Legends `Exterior`/`Skin`도 정상 처리해요. 별도 선체 모델이 없으면 선택한 기본 선체를 유지하며 대기열을 중단하지 않아요.
- Incomparable SE가 `PBES709_INCOMPARABLE_EXCLUSIVE has no A_Hull model` 오류로 실패하던 문제를 고치고, `mat_SteelStyle2021` 재질 스타일을 조립 메타데이터에 보존해요.
- 실제 Incomparable SE로 전투 하드포인트 99/99개, 장식 배치 610/610개, PBR 모델 83개, 렌더 세트 116/116개, 편집 파트 757개와 텍스처 440개를 누락 없이 추출·조립했어요.
## 5.0.57 Legends 고유 외형·중첩 무장 배치 수정

- Legends GameParams에 연결된 기본 `Exterior`/`Skin` 레코드를 자동 적용해, 공용 선체의 위장이 벗겨진 모습 대신 함선 프리뷰와 같은 고유 외형을 추출해요. Mecklenburg G는 황금 전용 `GSB423_Mecklenburg_Birthday_26` 선체, `GGM3162` 주포, `GGS3163` 부포와 전용 텍스처를 사용해요.
- 포탑 위 대공포 좌표는 부모 포탑의 원래 장착 행렬에서 합성하고, 메시 축 보정은 자식 하드포인트에 다시 적용하지 않아요. Mecklenburg G 2·3번 포탑의 대공포 4개가 포탑 반대쪽으로 뒤집히던 문제를 고쳤어요.
- 실제 Mecklenburg G로 전투 하드포인트 68/68개, 모델 67개, 렌더 세트 116개, 편집 파트 508개, 텍스처 306개를 누락 없이 추출·조립했어요.
- Legends UI에는 개별 위장 선택은 아직 제공하지 않지만 특수 함선의 고유 외형과 전용 모델은 자동 적용된다고 명확히 표시해요.

## 5.0.56 모델 뷰어 로딩 속도 개선

- 같은 MTL 텍스처 참조를 한 번만 디코딩하고, 동일한 이미지와 재질 변형을 여러 편집 파트가 공유해 중복 메모리와 GPU 업로드를 줄였어요.
- 최초 모델 표시에는 알베도와 알파만 읽고, 법선·거칠기·AO는 **PBR 상세 미리보기**를 켤 때 불러와요. 뷰어에서 사용하지 않는 기존 specular 맵은 더 이상 선로딩하지 않아요.
- WebView2가 지원하면 `ImageBitmap` 비동기 디코딩을 사용하고, 지원하지 않으면 기존 `TextureLoader`로 자동 전환해요. `OBJLoader`가 이미 단독 소유한 지오메트리도 다시 복제하지 않아요.
- 동일한 헤드리스 Edge 검사에서 실제 519파트 Mecklenburg G는 131.7초에서 21.8초로 약 83% 빨라졌고, 리소스 요청은 262회에서 55회, 최장 메인 스레드 멈춤은 87.2초에서 약 1.0초로 줄었어요. PBR 채널은 선택 시 약 3.4초에 추가로 준비됐어요.

## 5.0.55 무손실 추출 속도 개선

- 무손실 PNG 압축을 최대 4개 작업으로 병렬 처리하고, 디코딩 픽셀 기준 공유 캐시를 사용해 PC판·코라블리 재추출에서는 같은 텍스처를 다시 압축하지 않아요. 출력은 독립 복사본이라 편집해도 캐시를 건드리지 않아요.
- 이미 해결한 PBR 원본 선택을 캐시하고 독립 패키지 묶음을 2개씩 읽어, 품질을 유지하면서 반복 별칭 탐색과 순차 대기를 줄였어요.
- Legends의 서로 독립적인 리소스는 4개 작업으로 병렬 추출하며 CRC 기록과 결과 순서는 그대로 유지해요.
- 실제 Patrie는 첫 PBR 변환이 105.7초에서 46.9초, 재추출이 26.7초에서 7.5초로 줄었어요. Mecklenburg G의 234개 Legends 리소스 추출은 23.3초에서 15.9초로 줄었어요.
## 5.0.54 무손실 출력 최적화와 Legends 중첩 무장 수정

- PC판·코라블리 OBJ 출력에서 같은 역할·같은 픽셀의 중복 텍스처를 합치고, 단일 채널 PBR 맵을 무손실 grayscale PNG로 저장하며 PNG 압축률을 높였어요. 실제 Patrie 기본 출력은 OBJ와 디코딩 픽셀을 바꾸지 않고 ZIP 약 213.2MB에서 88.7MB로 줄었어요.
- 이미지 이름이 해시뿐이어도 재질 이름을 이용해 MFM을 찾도록 고쳐 PBR 채널이 조용히 빠지지 않게 했고, 변환·음성 캐시 형식도 버전으로 분리했어요.
- 주포탑 위 대공포처럼 부모 무장 안에 달린 Legends 중첩 하드포인트를 좌표 합성해 배치해요. 실제 Mecklenburg G는 전투 하드포인트 68개를 모두 해결하고 전체 OBJ/PBR 추출을 통과했어요.
- PC판·코라블리 위장과 2차 색상 선택을 확장하고, 위장 이름을 프로그램 언어에 맞춰 표시해요.
- Legends 함선 목록을 선택한 클라이언트 자료에서 완전하게 구성해 기존 누락 함선을 복구했어요.
## 5.0.53 읽기 쉬운 텍스처 파일명

- PC판·코라블리·Legends 최종 텍스처를 파트/재질 이름과 `_albedo`·`_normal`·`_ao`·`_roughness`·`_metalness` 채널 접미사가 붙은 읽기 쉬운 이름으로 저장해요.
- 같은 이름이 겹칠 때만 `_02`·`_03` 번호를 붙이고, SHA-256 이름은 내부 중복 방지 캐시에만 남겨요.
- OBJ·MTL·PBR 참조를 새 파일명으로 함께 갱신하고, 원본 식별자와 SHA-256 대응 정보는 `texture_manifest.json` 에 기록해요.
- 원본 이름이 해시뿐인 텍스처는 연결된 재질 이름으로 바꿔 Blender 같은 외부 OBJ 도구에서도 정상적으로 불러올 수 있게 해요.

## 5.0.52 깔끔한 Legends 추출 폴더

- 검증을 통과한 Legends 함선은 OBJ·MTL·모델/검증 보조 파일과 `textures` 폴더를 함선 출력 폴더 바로 아래에 배치해요.
- 성공한 추출에서는 불필요한 `scene` 단계와 다시 만들 수 있는 `generated`·`extracted`·`pbr` 중간 폴더를 정리해요.
- 파이프라인 로그와 내부 매니페스트는 `%LOCALAPPDATA%\WoWSToolbox\Diagnostics\Exports`로 옮겨 일반 출력 폴더에는 사용자가 여는 파일만 남겨요.
- 실패하거나 완료되지 않은 추출 폴더는 문제 분석을 위해 그대로 보존하고, 기존 추출 결과는 변경하지 않아요.
## 5.0.51 표면 검사 모드·영구 위장 캐시 복구

- **알베도 검사**와 **PBR 상세 미리보기**를 상호 배타적으로 바꿨어요. 알베도 검사를 끄면 숨겨진 방향광 상태가 되살아나지 않고 언제나 균일한 기본 표면 표시로 돌아가요.
- 두 검사 모드가 동시에 저장됐던 이전 뷰어 설정은 새 설정 형식으로 자동 초기화해요.
- 예전 PC판·코라블리 카탈로그가 빈 영구 위장 배열을 최신 데이터로 오인하지 않도록 카탈로그 형식 버전을 기록하고, 오래된 캐시는 한 번 자동 재생성해요.
- 현재 PTS의 Vanadis에 연결된 영구 위장 8개를 모두 확인했으며, 기본 선택은 계속 "위장 없음 · 기본 상태"예요.
- 실제 PTS 카탈로그와 자체 검사로 새 위장 목록·뷰어 상태 계약을 확인해요.
## 5.0.50 함선별 영구 위장 보관함

- 함선 선택 창에 **도색 보관함**을 추가하고 기본 선택을 언제나 `위장 없음 · 기본 상태`로 유지해요.
- PC판과 Korabli는 현재 선택한 함선에 실제로 연결된 영구 위장만 표시하며, 번역된 이름과 안정적인 내부 ID를 함께 사용해 동명이거나 여러 종류인 위장을 구분해요.
- 같은 함선의 여러 영구 위장 중 하나를 함선별로 고를 수 있고, 선택값은 각 대기열 항목·출력 폴더·추출 캐시에 독립적으로 적용돼요.
- 대기열 저장 파일에 위장 ID·이름·도색 방식을 보존하고, 이전 버전 대기열 파일은 자동으로 기본 상태로 불러와요.
- 이벤트·콜라보 함선처럼 여러 Vehicle이 같은 모델 폴더를 공유해도 정확한 함선 레코드를 기준으로 위장과 무장을 해석해요.
- Legends는 신뢰할 수 있는 함선별 영구 위장 연결 정보가 확인될 때까지 `위장 없음 · 기본 상태`만 허용해요.
- 실제 PC판 Aki G의 `Skyward Grace` 추출과 9단계 전체 자체 검사를 통과했어요.

## 5.0.49 장갑 양면 표시·영구 위장 디테일 보존

- 아래쪽이나 내부 시점에서도 선택한 장갑판이 사라지지 않도록 장갑판을 양면으로 표시해요.
- 장갑의 깊이 테스트·깊이 기록·단일 패스 투명도는 유지해 가까운 장갑이 뒤쪽 장갑을 계속 가려요.
- 작은 위장 색상 타일로 원본을 덮지 않고 고해상도 기본 알베도 위에 영구 위장 타일을 합성해요.
- 원본 표면 디테일과 알파를 보존하면서 위장 UV 이동·배율을 베이킹에 반영해요.
- 새 exporter fingerprint로 이전의 잘못된 GLB 캐시가 자동 재사용되지 않게 했어요.
- 텍스처 합성 단위 테스트·릴리스 exporter 빌드·실제 New Jersey 장갑 회귀 검사·9단계 자체 검사를 통과했어요.

## 5.0.48 영구 위장 추출·장갑 외형 투명도 조절

- 장갑판 불투명도와 별개로 뒤쪽 외형 함선의 불투명도를 직접 조절하고 사용자 설정을 기억해요.
- PC판과 코라블리에서 함선별 고유 영구 위장을 선택해 OBJ·MTL 기본 재질로 내보낼 수 있어요.
- 네이티브 GLB를 OBJ로 변환할 때 `KHR_texture_transform`의 UV 이동·배율·회전·텍스처 좌표 채널을 보존해 위장 배치가 어긋나지 않게 했어요.
- 기본 도색과 영구 위장 추출 캐시를 분리해 다른 도색의 이전 결과가 재사용되지 않게 했어요.
- 실제 Aki 영구 위장과 Aragón 장갑 뷰어, 합성 UV 변환 자료로 추출·표시 과정을 검사했어요.
- Legends는 별도 조립 형식에서 신뢰할 수 있는 영구 위장 계약이 확인될 때까지 검증된 기본 도색 추출만 지원해요.

## 5.0.47 균일 검사 조명·장갑 외형 가시성 개선

- 일반 모델 모드를 무조명 기본색 재질로 바꾸고 모든 OBJ 파트에 같은 스튜디오 밝기 계수를 적용해, 법선·미러링·분리된 파트 원점 때문에 도색이 가짜 투톤으로 갈라지지 않게 했어요.
- 노출·주광·환경광 조절은 계속 반응하지만 일반 모드에서는 방향에 따른 명암을 만들지 않아요. 실제 방향광은 **PBR 상세 미리보기**에서만 사용해요.
- **알베도 검사**는 톤 매핑을 무시한 원본 텍스처 진단 모드로 유지했어요.
- 내부 장갑을 가리지 않는 외형 함선의 불투명도를 조금 높여 위치 문맥을 더 읽기 쉽게 했어요. 장갑판의 깊이 테스트와 깊이 기록은 그대로 유지해요.
- 실제 74파트 Aragón 추출본으로 균일 일반 조명·원본 알베도·선택형 PBR·장갑 깊이·모델 복원 전 과정을 검사했어요.
## 5.0.46 장갑 외형 문맥·조명 반응 복구

- 일반 모델의 기본 재질을 중립 조명 재질로 되돌려 노출·주광·환경광 조절이 실제 함선 표면에 반영돼요.
- **알베도 검사**는 조명을 무시하는 진단 모드로 분리했어요. 끄면 중립 조명 재질로 돌아가고, **PBR 상세 미리보기**는 별도 선택 모드로 유지돼요.
- 장갑 모드에서는 함선 외형을 낮은 불투명도의 중립 문맥으로 남겨 장갑 위치를 이해할 수 있어요. 이 외형은 깊이를 기록하지 않아 내부 장갑을 가리지 않아요.
- 실제 장갑판은 계속 깊이를 기록하므로 가까운 갑판·바벳·측면·격벽이 뒤쪽 장갑을 가려요. 필터를 적용해도 장갑 덩어리만 허공에 남지 않아요.
## 5.0.45 장갑 깊이 가림 복구

- 장갑 불투명도를 조절해도 보이는 장갑판이 깊이 버퍼를 기록하도록 고쳤어요.
- 가까운 갑판·측면·포탑 전면·격벽이 뒤쪽 장갑을 가려, 갑판 아래 바벳과 반대편 장갑이 X-ray처럼 섞여 보이지 않아요.
- 장갑판은 앞면 표시를 유지하고 일반 함선 모델은 장갑 모드에서 계속 완전히 분리돼요.
- 실제 추출 함선을 브라우저에서 열어 장갑 깊이 테스트·깊이 기록·가림 재질 계약을 검사해요.

## 5.0.44 장갑 완전 분리·중립 도색·Legends 진단

- 장갑 모드에서는 일반 함선 메시를 전부 숨겨 선체 도색과 상부구조 텍스처가 내부 장갑을 가리지 않게 했어요.
- 일반 모델 모드는 원본 기본색 텍스처를 무조명 도색 재질로 보여줘요. 방향성 PBR 조명은 선택형 미리보기에서만 사용해 기본 도색을 바꾸지 않아요.
- 모델 모드로 돌아오면 장갑 모드 진입 전의 파트별 표시 상태를 정확히 복원해요.
- Legends에서 발견한 전체 레코드 수와 완전 조립 가능한 함선 수를 따로 표시해요. 목록의 468척은 발견된 995개 중 지원되는 조립 가능 항목일 수 있어요.
- Legends 조립 중 자식 프로세스의 시작·진행 신호·완료·경과 시간·로그 경로를 기록해 오래 걸리거나 멈춘 정확한 단계를 찾을 수 있게 했어요.
- 실제 추출 함선으로 기본 도색·선택형 PBR·장갑 완전 분리·모델 복원을 브라우저 회귀 검사했어요.

## 5.0.42 GM3D 호환 재질·PBR 채널 분리

- GM3D의 Aki G OBJ·MTL·텍스처와 직접 대조하여 기본 OBJ 재질 계약을 동일하게 맞췄어요.
- `_a`는 원본 도색, `_mg`의 R 채널은 회색 반사맵, `_n`은 노멀, `_ao`는 AO로 연결해 일반 OBJ 로더에서 원본 색을 우선해요.
- 금속성·거칠기 세부 채널은 표준 MTL 주석으로 보존하고 내장 뷰어의 선택형 PBR 미리보기에서만 사용해, 조명 아래 생기던 검은 표면과 가짜 투톤을 막았어요.
- Korabli 색인 재질의 AO가 G 채널에 들어 있는 경우도 자동 판별해 올바른 채널을 사용해요.
- 실제 Aki G 추출본과 Chromium 기반 MTL 로더 테스트로 도색·반사·노멀·AO·선택형 PBR 채널을 검증했어요.

## 5.0.41 원본 도색·Legends 조립 좌표 복구

- 이벤트·콜라보 함선은 정확한 GameParams 레코드로 해석하여, 같은 모델 폴더를 공유하는 Aki G·AL Hindenburg 같은 함선이 무장 없이 선체만 추출되던 문제를 막았어요.
- 기본 뷰어는 원본 색상 도장 재질을 유지하고 노멀·거칠기·AO는 선택형 PBR 미리보기에서만 사용해, 서로 무관한 파트가 검게 변하거나 가짜 투톤으로 갈라지지 않게 했어요.
- 업그레이드 설치본에 남아 있던 저노출 조명 설정은 한 번 초기화하여 중립적인 기본 조명으로 열어요.
- Korabli의 전체 `_art` 도장 아틀라스를 우선하고, 끝부분만 잘린 BC7 아틀라스는 안전한 범위에서 복원해 16/32px 대체 텍스처로 떨어지지 않게 했어요.
- Legends ModelUber의 선수 방향 축 변환을 바로잡아 주함포·부함포·사격 지휘기·레이더·기타 장비가 원래 선체 구간에 배치돼요.
- PC Aki, Korabli Hanko·Moonsund, Legends Connecticut을 실제 추출하고 참고 텍스처 통계 및 부품 좌표와 대조했어요.
- 외부 참고 압축파일은 로컬 검증에만 사용하며 저장소와 배포본에는 포함하지 않아요.
## 5.0.39 추출 무결성·뷰어 법선 복구

- Three.js의 표준 양면 법선 처리를 복원했어요. 카메라를 향한 역방향 선체·갑판·포탑·캐터펄트·상부구조물 면이 주광 아래에서 검게 변하지 않아요.
- 위험한 GLB 프리미티브 중복 제거를 없앴어요. 같은 접근자를 공유해도 의도적으로 반복된 함선 그리기 항목은 모두 보존해요.
- 불완전한 스트리밍 `.dd0` 텍스처 조각은 디코딩 전에 거부하고 실제로 디코딩 가능한 DDS 데이터만 사용해요.
- PC·Korabli의 중첩 visual 프로토타입을 실제 말단 모델까지 해석해 부모 조립체나 대체 형상이 파트로 나오는 문제를 막았어요.
- PC·Korabli 추출 바이너리 2개를 다시 빌드하고 뷰어·네이티브 OBJ 변환 회귀 계약을 추가했어요.
- Korabli Moonsund, PC Aki, Legends Suwo를 현재 Blender 없는 파이프라인으로 다시 검증했어요.
## 5.0.38 크기 조절 파트 패널과 편집 단순화

- 모델 뷰어 오른쪽 파트 패널의 왼쪽 경계를 끌어 전체 너비를 원하는 만큼 조절할 수 있어요.
- 검색·분류, 선택 파트 카드, 파트 목록 사이에 높이 조절선을 추가하고 사용자별 배치를 기억해요.
- 검색창 아래 분류 필터가 여러 줄로 표시되며 자체 스크롤을 사용해 아래 항목이 가려지지 않아요.
- OBJ에 완전한 관절 계층이 없어 오동작하던 임의 파트 회전, 무장 선회, 포신 앙각 기능을 제거했어요.
- 이동, 단독 보기, 숨김, 원위치와 Ctrl+Z/Ctrl+Y는 그대로 사용할 수 있어요.

## 5.0.37 함선 표면·텍스처 선택 복구

- 일반 함선 파트는 안정적인 양면 표시로 되돌렸어요. 원본 면 방향이 섞인 갑판·포탑·캐터펄트·상부구조물이 내장 뷰어에서 사라져 공중에 줄지어 보이던 현상을 고쳤어요.
- 장갑판은 앞면만 표시하고, 색상을 그리지 않는 양면 함선 깊이 메시로 가려요. 가까운 장갑은 보이되 반대편 장갑이 함선을 투과해 보이지 않아요.
- 일반 재질은 원본 `_a` 도장 텍스처를 우선하고, `_a`가 아주 작은 색인표이며 `_art`가 충분히 클 때만 `_art`를 사용하도록 자동 판별해요.
- 일반 재질과 색인 재질을 각각 검사하는 회귀 테스트를 추가하고 PC·Korabli 추출 바이너리 2개를 같은 수정본으로 다시 빌드했어요.
- 파트 중심점의 좌표계를 OBJ 기준으로 명시하고 추출기·뷰어 계약 검사를 추가했어요.

## 5.0.36 파트 회전·이동식 조명 패널

- 단일 파트를 선택하면 무장 인식 여부와 관계없이 X·Y·Z 회전값을 항상 표시해요.
- 무장 선회는 추출 데이터의 함선 수직축만 조절하며, 다른 두 축의 회전값을 지우지 않아요.
- 선택 파트 카드에서 포탑 선회와 지원되는 포신 앙각을 조절하고, 독립 포신 형상이 없는 OBJ는 그 이유를 표시해요.
- `조명과 표면` 패널 헤더를 마우스로 끌어 옮길 수 있고 위치를 기억해요. 화면 밖으로 나가지 않으며 `위치` 버튼으로 초기화할 수 있어요.
- 숫자 회전·선회·앙각·원위치 편집은 Ctrl+Z와 Ctrl+Y 기록에 포함돼요.

## 5.0.35 인덱스 재질·장갑 가림·항공 장비 추출 보정

- 조명과 PBR 채널을 제외하고 원본 색상 텍스처만 확인하는 `알베도 검사`를 추가했어요.
- 장갑 보기에서 반대편 모델 표면과 무장 모델이 비쳐 보이던 현상을 막았어요.
- `airArmament`와 `depthCharges` 조립 계통을 추가하여 게임 데이터에 존재하는 North Dakota의 캐터펄트 2개를 추출해요.
- Moonsund 같은 인덱스 재질이 작은 `_a` 색인표를 사용하지 않고 원본 해상도의 `_art` 색상 텍스처를 사용해요.
- OBJ 변환 중 완전히 중복된 프리미티브를 제거하고, 고밀도 함선은 뷰어 픽셀 밀도를 자동 조절해요.

## 5.0.34 전 파트 재질 표시 일관성 보정

- 선체·상부구조물·주함포·부함포·대공포·레이더·캐터펄트 등 OBJ의 모든 파트에 같은 재질 정책을 적용해요.
- OBJ 면 방향이 섞인 부분에서 카메라 쪽 면의 조명 법선을 반대로 뒤집던 동작을 막아, 하나의 도장면이 두 색처럼 갈라져 보이던 현상을 고쳤어요.
- 기본 표시는 원본 base color를 우선하며, 추출된 노멀·거칠기·AO는 `PBR 상세 미리보기`를 켰을 때만 비파괴 방식으로 적용해요.
- 기본 조명을 넓고 중립적으로 조정하고, 모델을 닫을 때 숨겨진 PBR 텍스처도 안전하게 정리해요.

## 5.0.33 PBR 텍스처와 모델 뷰어 조명 보정

- 원본 크기의 base color와 함께 노멀·거칠기·금속성·AO 보조 텍스처를 추출하고, OBJ 옆의 PBR 매니페스트로 연결해요.
- 게임 전용 `_mg` 채널을 일반 WebGL 금속성으로 단정해 함포와 도장이 검정·흰색으로 갈리던 뷰어 문제를 막았어요. 추출 데이터는 보존하되 기본 미리보기는 도장 재질로 안전하게 표시해요.
- 그림자를 만드는 강한 직사광을 기본값에서 없애고 AgX 톤 매핑과 중립적인 스튜디오 조명으로 바꿨어요.
- 3D 모델 뷰어 오른쪽에 `조명과 표면` 패널을 기본으로 열어 노출·주광·환경광·표면 굴곡·광원 방향을 바로 조절할 수 있어요.
- 해수면 높이는 함선 모델의 실제 Y 위치를 포함해 계산하고, 추출기·뷰어·매니페스트 회귀 검사를 추가했어요.

## 5.0.32 PC 최신 빌드 호환성과 카탈로그 정확도

- PC 빌드 13015811의 GameParams에서 사용되는 RPC `FLOAT64` 형식을 지원해 추출기가 종료되던 문제를 고쳤어요.
- 현재 게임 패키지에 실제 선체 geometry가 있는 변형만 카탈로그에 표시해 `Hiryū (old)` 같은 제거된 구형 함선을 선택하지 않게 했어요.
- 카탈로그가 확인한 정확한 선체 업그레이드를 모델·장갑 추출기에 전달해 변형 불일치를 줄였어요.
- 내보내기 실패 시 마지막 도구 출력을 보존하고, 지원하지 않는 데이터 형식과 누락된 geometry를 사용자가 이해할 수 있게 안내해요.
- 설치 후 열리는 `README.txt`는 변경 이력 대신 한국어·영어 빠른 사용법만 담도록 정리했어요.
- 프로그램의 한국어 안내 문구를 `~입니다/~합니다` 형식으로 통일했어요.
## 5.0.31 GitHub 업데이트 확인

- 프로그램을 열면 화면을 막지 않고 GitHub Releases의 최신 정식 버전을 확인해요.

- 설정에서 시작 시 자동 확인을 끄거나 `지금 확인`으로 수동 검사할 수 있어요.
- 업데이트 확인 실패는 프로그램 시작과 모델 추출을 막지 않아요.
## 5.0.30 영어 기본값과 GitHub 공개 준비

- 새 설치와 포터블 배포본은 영어를 기본 언어로 사용하고, 설치 언어 화면에서도 영어를 먼저 선택해요. 기존 설치에서 선택한 언어는 업데이트 때 그대로 보존해요.

## 5.0.29 안전한 WebView2 업데이트와 무손실 기본 품질

- 설치기의 강제 프로세스 종료를 없애고, 실행 중인 WoWS Toolbox가 있으면 정상 종료 후 다시 진행하도록 안내해 `msedgewebview2.exe`의 `0x80000003` 예외 팝업을 막아요.

- `export.json` 또는 Legends 결과에 모델 LOD·텍스처 원본 여부를 `quality_contract`로 남겨 결과를 확인할 수 있어요.

## 5.0.27 안정적인 장갑 표시와 인플레이스 업데이트

- 실행 중인 WoWS Toolbox가 있으면 설치기가 안전하게 닫고, 업데이트 완료 뒤 선택에 따라 다시 실행할 수 있어요.

## 5.0.25 세 게임 공통 Blender 없는 OBJ 정식판

- Legends는 기존 순수 Python 형상 디코더·배치 조립기를 사용하고, PC판·Korabli는 추출한 GLB를 내장 Python이 직접 읽어 파트별 OBJ/MTL/PNG로 변환해요.
- GUI는 세 게임 모두 `OBJ만 · 세 게임 공통 · Blender 불필요`로 고정하며 Blender 경로를 탐색하거나 추출 명령에 넘기지 않아요.
- 실제 검증에서 Legends Arleigh Burke는 Blender 없이 63개 독립 오브젝트, 317,870개 정점, 238,124개 면을 가진 OBJ를 약 41초에 만들었어요.
- PC판과 Korabli Erie도 각각 13개 독립 파트와 텍스처 5개, 정확 장갑 40그룹을 Blender 없이 만들었어요.
- 영어 모드에서는 Python 자식 프로세스와 대기열 JSON을 포함한 실행 로그 전체를 영어로 변환해요.
- Windows PowerShell 5.1과 PowerShell 7을 함께 지원하며, 둘 다 있으면 PowerShell 7을 먼저 사용해요.
- 전용 Python 3.10.11과 Pillow 12.3.0을 내장해 시스템 Python이나 Blender 설치가 필요 없어요.
- 설치기는 PowerShell 실행 환경과 WebView2 Runtime을 검사하고, WebView2가 없을 때만 Microsoft 서명 부트스트래퍼를 실행해요.
- 설치 중 시작 메뉴와 바탕화면 바로가기를 각각 선택하며, 일반 실행은 CMD가 아니라 콘솔 창 없는 `WoWS Toolbox.exe`가 담당해요.

## 5.0.23 리플레이 도구 제거와 한국어·영어 UI

## 5.0.19 수정 사항

- 추출 화면의 게임 소스 바로 아래에 현재 설치본 경로와 `게임 폴더 선택` 버튼을 추가했어요.

- 게임 루트 대신 그 아래의 `bin`, `res_packages` 같은 폴더를 골라도 최대 네 단계 위에서 실제 게임 루트를 찾아요.
- 라이브 서버와 공개 테스트 서버처럼 같은 종류의 클라이언트가 여러 개여도 설치 경로마다 함선 목록 캐시를 따로 저장해 서로 덮어쓰지 않아요.
- 대기열의 각 함선에 원래 게임 설치 경로를 함께 저장해, 라이브 서버와 테스트 서버 함선을 한 대기열에 섞어도 각자 올바른 클라이언트에서 추출해요.
- `.wowsqueue.json`에도 설치 경로를 기록하며, 경로가 없던 이전 대기열 파일은 현재 설정 경로를 사용해 그대로 불러와요.

## 5.0.19 수정 사항

- 모델 뷰어에서 주함포·부포·대공포를 선택하면 `무장 축 제어` 패널이 나타나고, 추출된 엔티티 원점을 중심으로 `-180°~180°` 선회각을 지정할 수 있어요.
- 무장 회전 기즈모는 함선 좌표계에 맞는 수직축 하나만 표시해 포탑이 옆으로 넘어지지 않고 자체 중심축으로 돌아가요. 원점 정보가 없는 일반 OBJ는 해당 파트의 형상 중심을 안전한 대체 축으로 사용해요.
- 하나의 OBJ 파트에 포탑 몸체와 포신이 합쳐져 있어도 연결 성분·길이·방향을 분석해 포신 형상을 자동 분리하고 `-15°~60°` 앙각을 조절할 수 있어요.
- 포신 판별 신뢰도가 낮은 파트는 몸체가 잘못 변형되지 않도록 앙각 조절을 비활성화하고, 선회 기능만 제공해요.
- 선회각과 포신 앙각은 기존 `Ctrl+Z` 실행 취소, `Ctrl+Y` 다시 실행, `원위치` 기능에 함께 포함돼요.
- 실제 Resistance 모델의 주함포 3기, 부포 6기와 여러 대공포를 대상으로 포신 자동 분리, 20° 앙각, 30° 선회와 엔티티 위치 고정을 검증했어요.

## 5.0.17 수정 사항

- 선체 OBJ 생성 뒤 선택 기능인 정확 장갑 JSON 변환만 실패해도 함선 전체가 실패 처리되던 문제를 막았어요. 정확 장갑 변환은 임시 파일에서 검증한 뒤 교체하며, 실패하면 Blender 기본 장갑 데이터와 완성된 모델을 유지해요.
- 손상된 `batch-history.json`에 문자열·빈 값·`NaN`이 섞여도 목록 갱신이나 대기열 시작이 중단되지 않게 잘못된 기록만 건너뛰어요.
- 번역 데이터가 공백뿐인 함선 이름은 내부 변형명으로 안전하게 대체하고, 정상 번역의 앞뒤 공백은 정리해요.
- 함선·포탑 geometry 파싱 실패가 Rust `panic`으로 프로그램을 닫지 않고 문제 부품 이름이 포함된 정상 오류로 전달돼요.
- meshoptimizer 버텍스 디코더의 정렬되지 않은 메모리 변환을 없앴고, 무제한 정수와 비정상 실수 변환도 중단 없이 손실 없는 문자열 또는 `null`로 기록해요.
- 실행 초기에 GUI가 실패하면 `%LOCALAPPDATA%\WoWSToolbox\launch-error.log`에 원인을 남기고 오류 대화상자에서 로그 위치를 알려줘요.
- 실패 보고서 자체를 저장하지 못한 경우에도 더 이상 조용히 삼키지 않고 표준 오류에 원인을 남겨요.
- 5.0.17 배포본은 새 패키징 스크립트가 깨끗한 작업 원본에서 생성하고, 파일 해시 목록과 폴더·ZIP 검증을 함께 실행해요.

## 5.0.16 수정 사항

- 장갑 JSON의 좌표계를 함선 OBJ와 같은 `Y-up / -Z-forward`로 통일해 선수와 선미가 서로 뒤집혀 보이던 문제를 고쳤어요.
- 장갑 내보내기 엔진이 삼각형마다 실제 두께, 장갑층, 재질과 구역을 함께 저장해 `25–26 mm` 같은 범위 대신 `25 mm`, `305 mm`처럼 정확한 값을 표시해요.
- 회전·이동된 포탑 장갑의 변환 행렬도 적용해 선체 장갑뿐 아니라 무장 장갑까지 실제 위치에 맞춰요.
- 뷰어에 `해수면` 버튼과 높이 조절기를 추가했어요. 현재 높이는 함선 좌표의 `Y` 값으로 바로 확인할 수 있어요.
- 이전 버전의 범위형 장갑 JSON에는 원래 정확값이 없으므로, 정확 두께가 필요하면 함선을 한 번 다시 추출해야 해요. 새 장갑 엔진 지문을 사용하므로 예전 범위 캐시가 잘못 재사용되지는 않아요.
- Resistance 실제 모델로 선수·선미 일치, 4,368개 장갑 삼각형, 18종 정확 두께, 해수면 표시와 브라우저 콘솔 오류 0개를 검증했어요.
## 5.0.15 수정 사항

- Resistance처럼 같은 OBJ가 Blender에서는 정상인데 내장 뷰어에서 카메라 쪽 선체·갑판이 뚫려 보이던 문제를 고쳤어요.
- 조립 검증 JSON이 없는 PC판·Korabli·일반 OBJ는 Blender 기본 표시처럼 모든 모델 파트를 양면 렌더링해 좌현·우현 어느 쪽에서도 외피가 사라지지 않아요.
- Legends OBJ는 조립 검증 JSON을 계속 사용해, 새 추출물은 앞면 렌더링을 유지하고 구형 반전 장착 부품만 선택적으로 양면 처리해요.
- 뷰어 정적 파일 버전을 `5.0.15`로 올려 WebView2의 이전 렌더링 코드가 남지 않게 했어요.

## 5.0.14 수정 사항

- 같은 OBJ가 Blender에서는 정상인데 내장 뷰어에서 포탑·부함포·캐터펄트가 검게 갈라지던 문제를 뷰어 쪽에서 고쳤어요.
- 조립 검증 JSON의 실제 변환 행렬을 읽어 음수 determinant 장착 부품만 Blender 기본 표시와 같은 양면 재질로 렌더링해요.
- 보정 재질을 부품별로 복제해, 공유 재질을 쓰는 정상 방향 부품까지 함께 뒤집히던 문제를 막았어요.
- WebView2가 이전 `viewer.js`를 계속 쓰지 않도록 HTML·CSS·JS 주소에 버전 값을 붙였어요.
- 설정에 `WoWS-Toolbox-v5.0.6\output` 같은 구버전 패키지 출력 폴더가 남아 있으면, 실행 중인 새 버전의 `output` 폴더로 한 번만 자동 이전해요. 사용자가 직접 고른 일반 폴더는 유지해요.

## 5.0.13 수정 사항

- Legends 조립 OBJ에서 음수 determinant 장착 부품의 face winding과 vertex normal을 함께 반전해, 새 추출 파일이 단면 렌더러에서도 바깥 면을 올바르게 표시해요.
- 이전 버전에서 이미 추출한 Legends OBJ는 내장 뷰어가 주함포·부함포의 반전 면을 자동 감지해 재추출 없이 정상 외피로 표시해요.
- 기본/비교 카메라의 near/far 범위를 모델 크기에 맞게 줄여 포탑 지붕처럼 가까운 면에서 깊이 정밀도가 흔들리는 현상을 줄였어요.
- Suwo 실제 597파트 OBJ에서 앞면·뒷면·양면 렌더를 비교해 검은 구멍의 원인이 텍스처가 아니라 반전된 face winding임을 확인했어요.

## 5.0.12 수정 사항

- Suwo·Dewa 주함포가 내장 뷰어에서 검게 뭉개지던 문제를 고쳤어요. 중립 톤매핑과 균일한 스튜디오 환경광을 사용해 Blender 재질 미리보기와 가까운 밝기로 표시해요.
- 주함포의 색상 텍스처·노멀맵·개별 파트 구조는 그대로 유지하고, 포탑 내부 바닥면이 튀어나오지 않도록 기존 앞면 렌더링도 유지해요.
- 비금속 함선 도장의 반사색과 광택을 한 단계 더 낮춰 밝기를 올려도 금속처럼 번쩍이지 않아요.
- 기존에 추출한 OBJ에도 뷰어 수정이 바로 적용되므로 함선을 다시 추출할 필요가 없어요.
## 5.0.11 수정 사항

- 3D 뷰어 상단에 `배경` 버튼을 추가해 남색 그라데이션과 분위기 격자를 켜거나 숨길 수 있어요.
- `B` 키로도 배경을 전환하며, 선택 상태는 저장되어 다음에 뷰어를 열 때 그대로 복원돼요.
- 배경과 3D 좌표 격자는 서로 독립적으로 켜고 끌 수 있어요. 배경을 숨기면 모델·장갑·도구 UI는 유지되고 단색 바탕만 남아요.
- 기존 장갑 뷰어를 실제 Erie 장갑 데이터로 다시 검증해 두께 색상, 구역 필터, 모델 투명 표시가 정상 작동하는지 확인했어요.

## 5.0.10 수정 사항

- 내장 3D 뷰어의 청록색 보조광과 과도한 하이라이트를 줄이고 중립 조명으로 바꿔, 도장된 함선 표면이 금속처럼 번쩍이던 현상을 완화했어요.
- Blender MTL의 기본 `Ks 0.5 / Ns 250`을 그대로 쓰지 않고 비금속 도장 정책으로 정규화해, 반사 강도와 광택을 낮추고 텍스처 원색을 보존해요.
- Blender가 접선 노멀맵을 `map_Bump`로 기록한 경우 뷰어가 실제 `normalMap`으로 전환해 미세 표면 방향을 올바르게 읽어요.
- 부품 이동·회전·버튼 회전·원위치·숨김의 최근 편집 이력을 최대 100단계 저장해요. `Ctrl+Z`로 실행 취소하고 `Ctrl+Y` 또는 `Ctrl+Shift+Z`로 다시 실행할 수 있어요.
- `G` 이동, `R` 회전, `Delete` 숨김, `Home` 전체 보기, `Esc` 선택 해제 단축키를 추가했어요. 검색창과 입력 칸에서는 기존 텍스트 편집 단축키를 가로채지 않아요.
- 재질과 단축키 수정은 내장 뷰어에 바로 적용되므로 기존에 추출한 OBJ도 다시 추출할 필요가 없어요.

## 5.0.9 수정 사항

- 스키닝된 주함포·부함포·레이더의 버텍스 노멀이 면 감김 방향과 반대인 경우를 디코더가 자동 판별해 뒤집어요. 검게 보이거나 색이 반전된 듯한 무장 음영을 최종 OBJ까지 바로잡았어요.
- Legends 노멀맵의 양의 Z 복원을 Pillow 연산으로 바꿔 4096×4096 실제 텍스처 계산을 약 10.9배 빠르게 했어요.
- 같은 함선의 468개 텍스처 참조를 부품마다 다시 PNG로 만들지 않고 183개 고유 소스만 공용 변환하며, 중복 파일 해시도 한 번만 계산해요.
- 가벼운 부품 준비는 기본 4개 작업으로 병렬 처리하고, 메모리를 많이 쓰는 Blender 변환은 기존 2개 제한을 유지해요.
- 최종 OBJ 조립은 482개 인스턴스를 Blender 명령으로 하나씩 실체화하지 않고 동일 행렬의 독립 메시로 직접 만들어요. 이미 PNG인 텍스처도 원본 바이트를 그대로 사용해 중복 렌더링을 없앴어요.
- 평소 추출은 OBJ 구조·재질·상대경로·텍스처 해시·좌표 경계를 빠르게 검증하고, 배포 검사는 완성 OBJ를 새 Blender 장면에 다시 불러오는 깊은 검증을 선택적으로 실행해요.
- Connecticut 실데이터 무캐시 변환에서 74개 부품 준비·GLB 변환 58.946초, 521개 편집 OBJ 조립 18.524초를 기록했어요. 장치와 게임 빌드에 따라 시간은 달라져요.
- 노멀 방향과 노멀 PNG는 추출할 때 OBJ/GLB에 반영되므로, 이미 뽑은 함선의 무장 음영을 고치려면 5.0.9에서 해당 함선을 다시 추출해야 해요.

## 5.0.8 수정 사항

- Legends의 `_n.dds`에서 R/G에 저장된 노멀 X/Y로 양의 Z를 다시 계산해, 주함포·부함포가 검거나 색이 뒤집힌 것처럼 보이던 Blender 음영을 바로잡았어요.
- 다른 폴더의 OBJ를 열 때 WebView 모델 폴더 연결을 새로 적용한 뒤 뷰어 페이지를 다시 불러와, 경로만 표시되고 화면은 비어 있던 문제를 막았어요.
- 모델을 열기 시작하면 이전의 빨간 오류 상태를 지우고, 실제 뷰어 오류는 작업 로그에도 남겨 원인을 바로 확인할 수 있게 했어요.
- 임시 폴더의 OBJ를 실행 중인 뷰어에 다시 연결해 실제 삼각형 수까지 검증하는 자동 회귀 테스트를 추가했어요.
- 노멀 PNG는 추출할 때 생성되므로, 이미 추출한 함선의 무장 음영을 바로잡으려면 5.0.8에서 해당 함선을 다시 추출해야 해요. 뷰어 로딩 수정은 기존 OBJ에도 바로 적용돼요.

## 5.0.7 수정 사항

- 함선 선택 창에서 이름·국가·함종·티어·코드 칸의 행을 더블클릭하면 그 정확한 내부 변형을 선택하고 대기열에 바로 적용해요.
- 추출 체크박스나 즐겨찾기 칸을 더블클릭했을 때 창이 뜻하지 않게 닫히지 않도록 즉시 적용 대상에서 제외했어요.
- 여러 함선을 고를 때는 기존처럼 추출 칸을 체크한 뒤 `대기열에 적용`을 누르면 돼요.
- 통합 검사가 접근 제한된 테스트 임시 폴더를 제품 코드로 오인해 멈추지 않도록 Python 검사 범위를 실제 코드 폴더로 한정했어요.

## 5.0.6 수정 사항

- 모델 언팩·추출 결과의 기본 위치를 프로그램 폴더 안의 `output`으로 바꿨어요.
- 프로그램을 열 때 `output` 폴더를 자동으로 만들고, 예전 기본값인 `문서\WoWS-Exports`를 쓰던 설정은 새 위치로 한 번 자동 이전해요.
- 사용자가 설정 화면에서 직접 선택한 다른 출력 경로는 그대로 보존해요.

## 5.0.5 수정 사항

- Legends ModelUber 부품 배치 행렬을 게임의 왼손 Y-up 좌표계에서 Blender Z-up 좌표계로 정확히 변환해, 레이더·대공포·잡부품이 선체 종방향 반대편에 떠 있던 문제를 바로잡았어요.
- OBJ를 표준 `-Z Forward / Y Up` 규약으로 내보내 Blender의 기본 OBJ 가져오기 설정만으로 수평 상태가 되게 했어요.
- 내장 뷰어가 5.0.4 이전의 Z-up OBJ와 5.0.5 이후의 Y-up OBJ를 크기 축으로 자동 판별해 둘 다 올바르게 표시해요.
- WebView 가상 폴더가 바뀌는 순간의 `Failed to fetch`를 최대 3회 재시도하고, 매핑 세대 쿼리로 이전 실패 캐시가 새 모델을 막지 않게 했어요.
- 비교 모델은 전용 `compare.local` 호스트를 검증하도록 고쳐 비교 OBJ가 보안 검사에서 잘못 거부되지 않아요.
- 파트가 수백 개여도 목록만 내부 스크롤되도록 뷰어 높이를 고정해, 3D 캔버스가 목록 길이에 밀려 빈 화면처럼 보이던 문제를 막았어요.
- 기존에 추출한 OBJ의 좌표와 부품 위치는 파일 안에 이미 굳어 있으므로, 교정된 결과가 필요하면 5.0.5로 한 번 다시 추출해야 해요.

## 5.0.4 수정 사항

- 출력 폴더가 게임 설치 폴더와 겹치거나 외부 폴더를 가리키는 링크·연결 지점이면 추출과 덮어쓰기를 시작하지 않아요.
- 장갑 JSON의 색상·라벨·구역·좌표를 검증하고 HTML 문자열 삽입을 없애 로컬 뷰어 데이터가 화면 코드를 바꿀 수 없어요.
- 모델과 비교 모델을 빠르게 연속 선택해도 이전 비동기 로딩 결과가 새 모델을 덮어쓰지 않아요.
- PBR 요약·변환 캐시는 변환 엔진 지문과 GLB·검증 JSON SHA-256이 모두 맞을 때만 재사용해요.
- 대기열 JSON은 크기·배열·게임 소스·함선 식별자를 검사하고, 실패해도 기존 대기열을 유지해요.
- 뷰어 경고 표시, WebView 외부 이동·새 창·다운로드 차단, 드래그 상태 정리, 비정상 알파 임계값 보정을 추가했어요.
- GUI 밖에서 직접 추출해도 중첩 PowerShell·Python 프로세스 전체가 UTF-8을 사용해 한국어 진행 문구가 CP949 오류로 중단되지 않아요.
- 직접 실행에서 지정한 `run-slug`와 실제 `_Full` 출력 폴더를 같은 규칙으로 만들고 검증해, 추출 성공 뒤 매니페스트를 다른 폴더에서 찾는 오판을 막아요.
- 카탈로그·단일 추출·대기열 진입점이 로컬 모듈을 읽기 전에 바이트코드 생성을 차단해 배포 폴더에 `__pycache__`가 생기지 않아요.
## 5.0.3 수정 사항

## 5.0.2 수정 사항

- 추출 준비 검사 뒤 `if` 명령 오류로 실제 추출이 시작되지 않던 PowerShell 반환문을 바로잡았어요.

- 모든 PowerShell 파일에서 `return if` 형태를 금지하는 정적 회귀 검사를 추가했어요.
## 5.0.1 수정 사항

- 검색어의 `[`, `*`, `?` 같은 문자를 일반 문자로 처리해 함선 검색이 멈추지 않아요.

- 진단 ZIP의 개인 절대 경로 마스킹과 캐시 유효성 검사를 강화했어요.

## 5.0 핵심 기능

### 원하는 함선을 쉽게 고르기

- 인게임 이름, 코드, 국가, 함종, 티어로 검색
- 여러 함선 동시 체크
- 현재 필터에 보이는 함선 전체 체크/해제
- 즐겨찾기와 최근 추출 필터
- Legends의 같은 함선 내부 변형을 정확한 모델 경로까지 구분
- Legends, PC판, Korabli 함선을 한 대기열에 함께 추가

### 대기열

- 마우스 드래그 또는 `위로`/`아래로` 버튼으로 순서 변경
- 대기열 JSON 저장·불러오기
- 성공한 항목은 자동 제거, 실패한 항목은 재시도를 위해 유지
- 현재 함선을 마친 뒤 일시 정지
- 안전 취소: 시작하지 않은 항목과 부분 출력은 임의로 삭제하지 않음
- 이전 실제 소요 시간에 기반한 예상 시간·용량
- 작업 완료 또는 일부 실패 Windows 알림

### 출력 형식

- OBJ + MTL: Blender 등 외부 편집기에서 각 파트를 개별 선택
- 세 게임 공통 OBJ 전용 테스트 계약: GLB/FBX를 만들지 않고 Blender를 호출하지 않음
- 1K, 2K, 4K 또는 원본 텍스처
- 최고·중간·저용량 LOD
- `.blend`는 만들지 않음

중간 LOD 파일에 실제 메시가 하나도 없는 함선은 빈 결과를 성공으로 처리하지 않고 최고 LOD로 자동 재시도해요. 그래서 해당 함선의 첫 추출은 두 LOD를 검사하느라 더 오래 걸릴 수 있어요.

### 파트와 장갑 검증

- 선체, 주함포, 부포, 대공포, 어뢰, 미사일 발사기, 레이더/센서 분류
- `export.json`과 `.model.json`에 파트 수, 분류, 부모, 자식, 피벗, 무장 수 기록
- 요청한 함선 코드와 실제 결과 코드를 비교하는 정확 선택 계약
- Legends 내부 변형 교차 오염 차단
- PC판·Korabli의 정확 장갑 두께를 모델과 별도 `.armor.json`으로 저장
- 장갑만 실패하면 일반 모델 결과는 보존하고 원인을 보고서에 기록

### 첫 추출 속도 개선

- PC판·Korabli의 일반 모델과 장갑을 서로 독립된 프로세스로 동시에 계산
- 현재 함선이 Blender 변환에 들어가면 다음 PC/Korabli 함선을 미리 계산
- 전체 대기열을 Python 프로세스 하나에서 처리해 반복 시작 비용 축소
- 텍스처 해시 중복 제거
- 게임 빌드·변환기·함선·LOD별 캐시 분리

캐시 재추출만 빠르게 만든 구조가 아니에요. 모델·장갑 병렬화와 다음 함선 선계산은 처음 뽑는 서로 다른 함선에도 적용돼요.

로컬 PC판에서 Erie와 Black Swan 두 척의 새 LOD별 모델·장갑 캐시를 만든 실제 대기열 검증은 총 40.8초가 걸렸어요. 각 함선의 모델·장갑 계산은 약 16~17초 동안 병렬 실행됐어요. 저장장치, CPU, 게임 빌드, 함선 크기에 따라 결과는 달라져요.

Korabli Erie에서 중간 LOD가 빈 메시를 반환한 실제 사례는 최고 LOD 자동 재시도까지 포함해 105.7초가 걸렸고, 최종 OBJ 13파트와 장갑 27그룹을 정상 생성했어요.

## 가장 쉬운 추출 순서

1. `WoWS-Toolbox-GUI.cmd`를 열어요.
2. 왼쪽 `설정`에서 `경로 자동 탐색`을 누른 뒤 `경로 검사`와 `설정 저장`을 해요.
3. `함선 추출`에서 게임 소스를 고르고 `목록 새로고침`을 눌러요.
4. `함선 추가·편집`에서 검색·필터 후 여러 함선을 체크해요.
5. `대기열에 적용`을 누르고 필요하면 순서를 바꿔요.
6. 출력 형식, 텍스처 크기, LOD를 고른 뒤 `추출 준비 검사`를 눌러요.
7. `대기열 모델 추출`을 누르세요.
8. 완료 후 `3D 모델 뷰어`의 `최근 추출 열기`로 확인해요.

선체만 추출하는 모드는 없어요. 선체와 확인된 무장·센서·부속을 함께 조립하고, OBJ 안에서 각 파트를 별도 오브젝트로 유지해요.

## 3D 모델 뷰어

기본 조작:

- 빈 공간 왼쪽 드래그: 카메라 회전
- 오른쪽 드래그: 카메라 이동
- 휠: 확대·축소
- 모델 또는 파트 목록 클릭: 파트 선택
- `Ctrl`/`Shift` 클릭: 여러 파트 선택
- `이동`: 선택 파트 위치 조절
- `원위치`: 선택 파트 위치와 크기 복원
- 오른쪽 패널의 경계·구분선 드래그: 패널 너비와 각 영역 높이 조절
- `단독 보기`/`숨김`: 가시성 변경
- 분류 버튼 클릭: 목록 필터
- 분류 버튼 오른쪽 클릭: 해당 분류 전체 숨김/표시
- `원근`/`정면`/`측면`/`상면`: 카메라 전환
- `격자`/`와이어`/`캡처`: 보조 표시와 PNG 저장
- `측정`: 표면 두 점 사이 거리
- `수선면`: 높이를 조절할 수 있는 시각 기준면

비교 보기:

1. 기준 OBJ를 먼저 열어요.
2. 상단 `비교 OBJ 열기`에서 두 번째 모델을 선택해요.
3. 뷰어의 `비교 겹침`을 누르면 좌우 비교로 바뀌어요.
4. `비교 닫기`로 두 번째 모델을 제거해요.

겹침 모드의 두 번째 모델은 반투명 청록색으로 표시돼 크기와 형상 차이를 확인하기 쉬워요.

장갑 보기(PC판·Korabli):

- `장갑`을 눌러 모델과 장갑 표시를 전환
- 두께 범위와 구역 필터 조합
- 장갑 불투명도 조절
- X/Y/Z 단면 위치 조절
- 장갑 표면을 가리켜 구역, 정확 두께, 장갑층, 시선 입사각과 유효 두께 확인

유효 두께는 현재 카메라 시선과 표면 법선으로 계산한 시각화용 근사값이에요. 게임의 도탄, 정규화, 구경 우세 등 실제 탄도 판정 전체를 재현하지는 않아요.

Legends는 PC판/Korabli와 같은 장갑 메시 계약이 확인되지 않아 장갑 모드를 만들지 않아요. 일반 모델과 무장 조립 OBJ는 지원해요.

## 결과 구조

PC판·Korabli 기본 출력:

```text
<함선 이름>_<코드>\
  <함선 이름>.obj
  <함선 이름>.mtl
  <함선 이름>.armor.json
  <함선 이름>.model.json
  export.json
  textures\
    *.png
```

WoWS Toolbox는 OBJ/MTL/PNG와 사용 가능한 정확 장갑 JSON을 생성해요.

WoWS Toolbox는 Legends·PC판·Korabli 모두 파트별 OBJ/MTL/PNG를 내보내요. Legends 최종 조립 OBJ는 `scene` 폴더, PC판·Korabli OBJ는 함선 결과 폴더에 있어요.

Blender에서 OBJ를 직접 가져올 때:

```text
Forward: -Z
Up: Y
```

OBJ, MTL, `textures` 폴더는 함께 옮겨야 상대 텍스처 경로가 유지돼요.

## 캐시·호환성·진단

- 캐시 위치: `%LOCALAPPDATA%\WoWSToolbox\Cache`
- `설정 > 캐시 상태`: 파일 수와 용량 확인

- `진단 ZIP`: 모델·텍스처·원본 로그·개인 경로를 넣지 않은 요약 보고서 생성

## 현재 제한

- 게임 런타임이 별도로 합성하는 카모·스킨을 임의로 추측해 적용하지 않아요. 확인된 선택 변형과 기본 재질을 내보내요.
- OBJ는 계층형 GLB의 모든 런타임 피벗을 그대로 표현할 수 없어요. 내장 뷰어는 함께 생성된 `.model.json`에 기록된 무장 피벗을 우선 사용해요.
- 뷰어의 수선면은 조절 가능한 시각 기준면이며 실제 흘수 메타데이터가 없는 모델에서는 자동 흘수가 아니에요.
- 게임 업데이트로 포맷이 바뀌면 특정 빌드가 실패할 수 있어요. 누락 장비를 꾸며내지 않고 실패 항목과 보고서를 남겨요.
